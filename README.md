# MeetXD ??

MeetXD is a modern, cross-platform video conferencing platform. It supports real-time video, audio, screen sharing, custom virtual backgrounds, and host anti-cheat controls. It is built using React, LiveKit (WebRTC), Node.js, Capacitor (for Android), and Tauri (for Windows).

## Features
- **Real-time Video & Audio:** High-quality, low-latency communication via WebRTC.
- **Cross-Platform:** Available on the Web, as a Windows Desktop App (Tauri), and an Android Mobile App (Capacitor).
- **Deep Linking:** Clicking an invite link directly opens the mobile or desktop app if installed.
- **Custom Backgrounds:** Blur or replace your background with images.
- **Host Controls:** The person who creates the room gets exclusive abilities to rename/remove participants and record the meeting.
- **Anti-Cheat Tracking:** Hosts can optionally enable tracking to see if participants switch tabs or leave the meeting window.
